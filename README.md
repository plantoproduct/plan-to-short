# Plan to Short — AI Studio Video Editor
**by Plan to Product**

Aplikasi desktop Windows untuk memotong video panjang menjadi klip pendek vertikal (`9:16`, `1:1`, `4:5`) siap upload ke TikTok, Reels, dan YouTube Shorts secara cepat dan offline.

---

## Unduh & Instalasi

1. Buka halaman **[Releases](https://github.com/plantoproduct/plan-to-short/releases)** dan unduh file **`PlanToShort_1.0.0_x64-setup.exe`** (~3,3 MB).
2. Jalankan file installer dan pilih folder instalasi sesuai keinginan Anda.
3. Buka aplikasi **Plan to Short**, lalu masukkan **Lisensi Key** Anda untuk aktivasi.
4. Masuk ke menu **Pengaturan ➔ Alat Media**, pilih folder penyimpanan alat media (misalnya di Drive `D:\`), lalu pasang komponen yang dibutuhkan (`FFmpeg`, `yt-dlp`, dan model teks).

---

## Fitur Utama

- **Ruang Kerja Multi-Proyek:** Kelola banyak proyek sekaligus di Sidebar tanpa kehilangan hasil edit sebelumnya.
- **Impor Link & File Lokal:** Mendukung link YouTube, TikTok, Instagram Reels, Facebook, X/Twitter, serta file video lokal (`MP4`, `MKV`, `MOV`, `WebM`).
- **8 Mode Framing & 8 Color Grade:** Layout otomatis (`Speaker Follow`, `Podcast Split`, `Gaming PIP`, `Full No-Crop`) dengan pratinjau real-time.
- **Subtitle Karaoke Interaktif:** Posisi, font, warna, dan highlight kata-per-kata dapat diatur langsung dan ikut ter-render ke video `.mp4`.
- **Akselerasi GPU & CPU Otomatis:** Mendeteksi perangkat keras secara otomatis (mendukung GPU NVIDIA NVENC & CPU Software Encoder).
- **Pembaruan Otomatis (Auto-Updater):** Cek dan pasang pembaruan langsung dari menu **Pengaturan ➔ Versi & Pembaruan**.

---

## Kebutuhan Sistem

- **OS:** Windows 10 / Windows 11 (64-bit)
- **Runtime:** Microsoft Edge WebView2 *(sudah terpasang bawaan di Windows 10/11 modern)*
- **Rekomendasi GPU:** NVIDIA GeForce GTX/RTX untuk ekspor NVENC lebih cepat *(tetap berjalan lancar di mode CPU)*
